== Introduction

Tool environment plugin lets you use "tools" in unusual ways, such as from shell scripts.

See http://issues.jenkins-ci.org/browse/JENKINS-4532[JENKINS-4532] for motivation.

== Variable names

A tool named `maven-3.9` is available as `MAVEN_3_9_HOME`: the name of the tool in capitals, each run of characters other than letters, digits and underscores replaced by one underscore, and `_HOME` added.

If a script expects another name, type it in the field next to the tool, for example `M2_HOME` or `JAVA_HOME`.
The tool is then defined under that name instead of the default one.
A name can use letters, digits and underscores and can't start with a digit.
Two tools can't share a name: the one that was ticked first is used and the build log says so.

The choice is saved in the `vars` field of the job as a comma separated list.
A tool with a name of your own is saved as `NAME=TOOL_HOME`, for example `M2_HOME=MAVEN_3_9_HOME,JAVA_HOME=JDK_21_HOME,ANT_1_10_HOME`.
